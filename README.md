# 會議記錄 App（安裝檔）

開會時按「開始」，畫面即時出字；結束後自動產出**分講者的繁體中文逐字稿**，並用你自己的 Claude 整理成**會議記錄**（摘要、決議、待辦）。
錄音、轉文字、分講者都在你自己的電腦上完成，**錄音不會上傳**。

這個頁面只放安裝檔。

## 安裝

**需要**：Apple M 系列晶片的 Mac、**macOS 14（Sonoma）以上**（記憶體建議 16GB 以上）、約 10GB 硬碟空間、Google Chrome（建議）。

1. 到右側的 **Releases**，下載最新版的 `MeetingNotes-xxxx.pkg`
2. 雙擊安裝檔，照畫面按「繼續」，輸入電腦密碼完成安裝
3. 打開「**會議記錄**」App（在「應用程式」資料夾，或用 Spotlight 搜尋）
4. 第一次打開會出現設定畫面：
   - **下載語音模型**（約 3.8GB，只要一次）
   - **連接你的 Claude**（建議；需要 Claude Pro 或 Max 訂閱）——按「登入 Claude」照畫面授權即可。沒有 Claude 也能用，只是沒有 AI 校正與會議記錄。

## 更新

App 會自動檢查新版本，側欄出現「有新版本」時按「立即更新」即可。

## 有問題

把 `~/Library/Logs/會議記錄.log` 傳給管理員。
